# CLAUDE.md

## Planning hand-off (read first, every session)
Planning and scope decisions for this project are made in a separate Claude chat, not here.

- At the start of every session, read `CHAT_HANDOFF.md` and follow its rules.
- Only build items listed under **Approved to build** in that file. Don't start anything else, even if it looks like an obvious next step.
- If a task needs a scope or design decision the file doesn't cover, write the question under **Questions for chat** and stop. Don't decide it yourself.
- When you finish an approved item, record it under **Done** (date, one line, run/commit reference).
